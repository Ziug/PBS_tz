## Трбования
- Python 3.10 или новее
- Зависимости из `requirements.txt`

## Установка
```bash
cd путь до папки, в которой будет сама система
python3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Импорт данных 
Таблицы должны быть в корне папки и иметь данные названия:
- `01_Заготовка.xlsx`
- `02_Потребность_сварки.xlsx`
- `03_Документация.xlsx`

```bash
python3 scripts/import_once.py
python3 scripts/classify_issues.py
```

После этого система работает только с `pbs.db`, исходные файлы больше не нужны

## Запуск
```bash
python3 -m uvicorn app.main:app
```
Открыть в браузере: **http://127.0.0.1:8000**
